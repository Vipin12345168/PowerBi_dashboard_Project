# PowerBi_dashboard_Project
This is a power bi end to end project
🏡 House Price Prediction | AI-Powered Real Estate Insights

✨ Turning Data into Smart Real Estate Decisions!

An end-to-end Machine Learning project that predicts house prices using intelligent data analysis and predictive modeling. Built with Python, Scikit-learn, and Flask, this project transforms property features into meaningful price estimates through an interactive and user-friendly web application.

🚀 Features:
• Machine Learning-Based Price Prediction
• Data Preprocessing & Model Training
• Interactive Web Interface
• Real-Time Price Estimation
• Smart Data-Driven Insights

💻 Tech Stack: Python | Flask | Scikit-learn | Pandas | NumPy | HTML | CSS

🎯 Project Goal: Making house price estimation smarter, simpler, and more accessible through Machine Learning.
